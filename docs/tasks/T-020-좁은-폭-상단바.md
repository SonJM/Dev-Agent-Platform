## 범위
1. 좁은 폭(기준 `max-width: 600px`, 값은 frontend-dev가 정하고 설명서에 근거)에서 06 §3.7 "4단계까지" 모바일 동작대로 상단바를 보정한다:
   - 탭 5개는 **아이콘만**(이름은 `title`·`aria-label`로 유지), 한 줄 안에 들어가지 않으면 탭 영역만 가로 스크롤(페이지 전체는 넘치지 않음).
   - 부가 요소(에이전트 칩, 버전, 배터리의 글자 라벨)는 숨기거나 아이콘·막대만 남긴다. 종(알림함)·테마·렌치(플랫폼 관리, 보일 때) 버튼은 남기고 누를 수 있어야 한다(터치 영역 44px 이상).
   - 브랜드 부제(`.brand .s`)는 이미 860px 이하에서 숨는다 — 그대로.
2. 768px 이상의 모양은 바꾸지 않는다(1440·768 스크린샷이 지금과 같아야 한다).
3. 다섯 화면(홈·에이전트·리서치·메신저·플랫폼) 모두 390px에서 **페이지 가로 넘침 없음**(`document.documentElement.scrollWidth <= 390`). 카드 본문이 넘치는 화면이 따로 있으면 고치지 말고 설명서 `제안`에 적는다(이번 범위는 상단바).
4. `node --check src/main/resources/static/ui.js`.
