2026-11-25 착수 전 재확인으로 **둘로 나눴다**. 이 작업은 "수집·요약·멘션·문서 RAG와 메신저 포트 축소"만 한다. 내장 운영 MCP·`운영` 질의·채팅 모델 포트는 [T-018](./T-018-운영-mcp-채팅-모델-제거.md)(이 작업 뒤)이 한다. 나눈 이유: 고칠 파일이 40개를 넘고, 채팅 모델 포트는 요약·멘션이 사라진 뒤에야 "사용처 없음"을 확인할 수 있다.

## 목적
사용자가 보내지 않은 메시지를 읽거나 저장하는 코드와 사내 문서 RAG가 저장소에 남아 있지 않고, `MessengerPort`가 "자기 대화의 새 메시지 받기"와 "자기 대화로 보내기"만 다룬다.

## 범위
1. **삭제**: 위 패키지·파일, 05 §2.2 이 작업 행의 API 8개(`/api/status` 포함 — 2026-11-25 PM 확인: 화면·`e2e/`·`deploy/`에 호출처 없음. 착수 때 `src/main/resources/static`·`e2e`를 다시 검색해 0인지 확인하고 설명서에 적는다), 스케줄(수집·요약·멘션·문서 적재), `db/schema.sql`의 테이블 5개(`chat_message`·`chat_room_cursor`·`chat_summary`·`mention_reply`·`doc_chunk`)의 `CREATE`·`DROP`·인덱스. 삭제 패키지 매퍼의 `ensureTable()`도 함께 사라진다(기존 설치의 남은 테이블은 Phase 2 종료 때 사용자가 DB를 비운다 — BOARD 「단계 종료 때 사용자가 할 일」).
2. **메신저 포트 축소**(D-4): 포트·서비스에서 방 목록·방별 조회·방을 고르는 전송·그룹 전송 정책을 없앤다. `notifySelf`·`notifyOn`·`sendToSelf`·`receiveSelf`·커서·`health()`·`selfTest()`는 그대로. `PortHealth`·`CallStats` 집계도 그대로.
3. **알림 유형 3개**: `GET /api/messenger-notify`가 `issue`·`research`·`system` 3개만 돌려준다. `POST`에 `summary`·`mention`이 오면 기존 "모르는 유형" 처리대로 거부한다.
4. **연동 카드에서 지식(RAG) 행 제거**: `GET /api/platform`의 `ports`에서 `knowledge`가 빠진다. 그 결과 홈 KPI 「연동」의 "지식(RAG) 확인 필요" 문구도 사라진다(화면은 응답을 그대로 그린다).
5. **T-006 검토 후속**(수집·멘션 제거와 같은 파일):
   - L-5 남은 흔적: `IssueAgentScheduler` 답변 폴링 로그 문구, `ChatMessageMapper.maxSelfSeq`(매퍼째 삭제), `IssueNotifier.warnIfSelfRoomNotCollected`, 설정 `bot.mention.command-keyword`, 안내 문구의 `@AI` 표기 — 이 작업이 고치는 파일(`AdminController`·`ResearchProperties` 주석·`gitlab/`·`messenger/`·`ops/`·`research/`)에서 지운다. 남는 명령 표기는 06 §4.2의 명령어(`이슈 …`, `질문 …`)로. `PlatformController`의 채팅·도구 모델 행 문구는 T-018.
   - L-3 대기 세션 수 집계 안내 문구가 수집 제거 뒤의 실제 집계와 맞는지 확인하고 고친다.
   - L-6 `messenger` ↔ `gitlab`·`research` 상호 참조(`MessengerCommandRouter` → `IssueAgentService`·`ResearchService`, 그쪽 → `MessengerService`): 정리 방법(예: 라우터를 코어 쪽 패키지로)을 정하고 근거를 설명서에 적는다. **동작은 바꾸지 않는다**. 옮기면 테스트 패키지도 같이.
   - M-6: `mention/`·`collect/`가 사라져 실제 메신저 어댑터(T-013)가 붙어도 답이 두 번 가거나 그룹방 글에 LLM이 답하는 경로가 없음을 설명서에 적는다.
6. **문서**: `README.md`·`CLAUDE.md`에서 수집·요약·멘션·문서 RAG·방 설정·방 목록 설명을 지운다(예: CLAUDE.md "한눈에" 표의 메신저 봇 행, 봇 메시지 접두어 함정의 `ChatMessageMapper.selectSelfAfter`·`CollectService.isBotGenerated`, "자기방 수집이 꺼져 있으면" 함정, `DocIngest` 로그 안내). 운영 MCP·채팅 모델·프리뷰 설명은 남긴다(T-018·T-009). 다른 절은 건드리지 않는다.
7. **버전** `build.gradle` 2.0.0(DB 스키마 비호환 — 04 §5).
8. 사용자 정의 MCP·`llm/UsageService`·`claude_usage`·`ClaudeCliProbe`는 건드리지 않는다.
