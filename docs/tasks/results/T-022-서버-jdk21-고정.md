# T-022 변경 설명서 — 서버 unit 의 JDK 21 고정과 smoke 프리뷰 흔적 정리

> 담당: backend-dev (backend-dev) · 2026-11-25 · 지시서: [T-022](../T-022-서버-jdk21-고정.md)

## 요약
서버 unit 틀과 절차서가 `<JAVA_HOME>` 을 JDK 21 로 고정하고 이유·확인 명령을 담는다(OI-29 ①). `server-smoke.sh` 에서 제거된 프리뷰 변수 `PREVIEW_ENABLED=false` 를 지웠다(OI-31 ①). JDK 21 로 띄운 Gradle 에서 `test bootJar` 가 통과함을 확인했다. 코드(`src/`)·toolchain 변경은 없다.

## 그림
그림 없음 — 주석·문서 문구와 스크립트 환경변수 한 개 삭제뿐이라 흐름 변화가 없다.

## 검증
- `grep -n "PREVIEW_" deploy/smoke/server-smoke.sh ; test $? -eq 1` → 일치 없음(rc=1)
- `grep -nE "JDK 21|JDK21" deploy/systemd/dev-agent.service deploy/README.md` → service 6행, README 표·§1 에서 일치
- `bash -n deploy/smoke/server-smoke.sh` → 문법 오류 없음
- `JAVA_HOME="$JDK21_HOME" ./gradlew --no-daemon test bootJar` → 통과(rc=0, 실패 0, `build/libs/dev-agent.jar` 생성). `JDK21_HOME` 은 세션에 없어서 이 PC 의 기존 설치(`~/.jdks/` 의 Corretto 21)를 지정했다(새로 내려받지 않음). 실행 JDK: `openjdk version "21.0.12" 2026-07-21 LTS`. toolchain 17 은 그대로.
- `bash deploy/smoke/server-smoke.sh` → **미실행 — 환경변수 없음**(`DEV_AGENT_SSH` 미설정, 서버에 접속하지 않음). 앱도 따로 띄우지 않음.
- 전체 테스트: 위 `test` 가 전체 테스트다.
