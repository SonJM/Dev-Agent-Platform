## 범위
- 서블릿 필터 하나로 접근 제어를 모은다.
  - `GET`·`HEAD`·`OPTIONS`가 아닌 `/api/**` 요청: `Origin`이 있으면 신뢰 목록(루프백 `http://127.0.0.1:<port>`·`http://localhost:<port>` + 설정 `access.allowed-origins`, 환경변수 `ACCESS_ALLOWED_ORIGINS`, 쉼표 구분, 정확히 일치)과 비교해 아니면 403. `Origin`이 없으면 통과.
  - 거부 응답은 05 §1.2 형식. 거부는 WARN 한 줄로 남기되 헤더 값 전체나 본문을 찍지 않는다.
- 컨트롤러의 개별 `foreign(req)` 호출 10곳을 없애고 `foreign()`을 지운다(필터가 대신한다).
- **엔드포인트 전수 조사**: 모든 컨트롤러에서 `GET`으로 상태를 바꾸는 엔드포인트를 찾아 표로 정리하고, `POST`로 바꾸거나(화면 호출부 `static/*.js`·`*.html`도 함께) 필터의 확인 대상에 넣는다. 화면 호출부를 고치면 `node --check`를 돌린다.
- 설정의 기본값은 빈 문자열이다(빈 값이면 지금과 같은 동작). 서버에서 쓸 값의 형태는 `https://<MagicDNS 이름>:8443`이다(값 자체는 저장소에 적지 않는다). `server.address`는 `127.0.0.1` 고정으로 두고 환경변수로 바꿀 수 있게 만들지 않는다.
- `build.gradle` 버전 1.13.0.
- 단위 테스트를 먼저 쓴다(TC-002, TC-003).
