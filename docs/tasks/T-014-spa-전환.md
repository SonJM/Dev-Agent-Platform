## 범위 (분할 예정 순서)
1. 기반: `web/`(Vite·React·TS strict·ESLint·Prettier·테스트), 빌드 결과를 jar 정적 자원으로 넣는 Gradle 연결, 공통 셸(S-06: 탭 바·상단바·알림함), 디자인 시스템 문서, API 클라이언트와 폴링·SSE 공통 처리
2. S-05 플랫폼 + S-04 메신저(설정 화면 — 가장 단순, 기반 검증용)
3. S-01 홈
4. S-03 리서치(루틴 포함)
5. S-02 에이전트(가장 큼: 실시간 로그·문서 카드·Diff 지연 그리기)
6. 플랫폼 관리 창
7. 정적 HTML·`ui.js`·`admin.js` 삭제, e2e를 SPA 기준으로 갱신(qa `유형: 유지`)

화면 하나를 옮길 때마다 옛 화면과 새 화면이 함께 떠 있을 수 있게 한다(경로 분리) — 매 지시서 끝에서 서버에 올릴 수 있어야 한다.
