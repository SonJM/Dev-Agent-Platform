## 1. 범위

### 1.1 대상
- 전환으로 바뀌는 것: Linux 기동, 접근 제어, 메신저 수신 경로, GitHub 연동, Telegram 어댑터, SPA.
- 전환 중 깨지면 안 되는 기존 화면 흐름(FR-6xx)의 회귀.

### 1.2 제외
- Claude CLI를 실제로 호출하는 흐름(이슈 분석·수정, 리서치 답변)의 자동 테스트 — 구독 토큰을 쓰고 결과가 비결정적이다. 사용자가 서버에서 수동으로 확인한다.
- 실제 GitHub·Telegram을 상대하는 자동 테스트 — 토큰이 필요하다. HTTP 응답을 흉내 낸 단위 테스트로 대신하고, 실제 연동은 사용자가 수동 확인한다.
- 서버에서의 `tailscale serve` 동작(FR-103) — 사용자가 절차서의 확인 항목으로 본다.

### 데이터 규모 가정

| 대상 | 가정 | 출처 |
|---|---|---|

| 스킬 / 루틴 / MCP | 각 수십 건. 루틴은 앱 상한 50건 | 사용자 추정 · 루틴 상한은 T-004 확인 |

QA seed(`e2e/seed/seed.ts`)는 스킬 60건(가정의 2배), 루틴 30건(상한 50이라 2배를 넣을 수 없다 — 여유 20을 남김, 실행되지 않게 비활성), 경계값 4행을 넣는다(T-004).

## 9. 증거의 경로 표기 (공개 저장소)

`OI-28` 결정 ①(2026-11-25, 사용자). 저장소가 공개라서 `docs/`에 올라가는 보고서·증거(qa 보고서, 변경 설명서, `report.json`, 스크린샷에 보이는 글)에 개발 PC·서버의 로컬 환경 정보를 남기지 않는다.

| 원래 값 | 쓰는 표기 |
|---|---|
| 사용자 홈(계정명이 든 경로) | `~` |
| 이 저장소의 절대 경로 | `<repo>` |
| 임시 폴더(OS·설치 소프트웨어 이름이 든 경로) | `<tmp>` |

- 계정명·서버 주소·IP는 어떤 형태로도 쓰지 않는다. 서버 접속은 환경변수 이름(`DEV_AGENT_SSH`)만 쓴다.
- 앱 로그(`T-xxx-qa/app.log`)처럼 절대 경로가 그대로 찍히는 원본은 `.gitignore`로 추적에서 뺀다(현재 qa 증거 폴더가 그렇게 한다).
- 스크린샷은 화면이 이미 `~`로 줄여 보여 주는 경로(예: 설치 점검의 작업 디렉터리 `~\…\e2e\test-results\qa-home`)면 그대로 둔다. 계정명·주소가 보이면 다시 찍거나 올리지 않는다.
- 이미 올라간 커밋 이력은 다시 쓰지 않는다. 2026-11-25에 T-002·T-007·T-008·T-015·T-018·T-019 qa 보고서의 임시 폴더 경로를 `<tmp>`로 바꿨다.
- PM은 검수 때 이 규칙을 본다(위반은 증거 보완으로 반려).
